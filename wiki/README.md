# Wiki Layer

`wiki/`는 raw source를 재사용 가능한 경력 지식으로 정규화하는 Knowledge layer다. 직접 제출하지 않고 이력서, JD 맞춤 brief, 면접 답변의 입력으로 사용한다.

## Core Files

- `overview/career-overview.md`: 현재 경력 요약과 우선순위
- `themes/positioning.md`: 반복 강점, 목표 역할, 포지셔닝
- `claims-ledger.md`: 이력서와 면접에 사용할 수 있는 주장 목록
- `proof-map.md`: claim을 뒷받침하는 source/proof 연결
- `sentence-bank/resume-bullets.md`: 재사용 가능한 이력서 bullet 후보
- `stories/story-bank.md`: STAR/CAR 스토리 후보
- `output-briefs/general-resume-brief.md`: 범용 이력서 조립 기준

## Rules

- 사실과 해석을 분리한다.
- 강한 claim은 반드시 raw source 또는 proof ID를 가진다.
- 근거가 부족한 항목은 claim으로 확정하지 않고 gap/caveat로 둔다.
- 새 경험, 프로젝트, 활동, 수상, 기술 페이지는 `wiki/templates/` 구조를 따른다.
