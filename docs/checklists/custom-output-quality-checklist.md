# Custom Output Quality Checklist

회사별 맞춤 패키지를 제출 후보로 보기 전 확인한다.

## JD Analysis

- [ ] target role이 명확하다.
- [ ] must-have와 preferred requirement가 분리되어 있다.
- [ ] 반복 키워드가 추출되어 있다.
- [ ] 평가자가 볼 가능성이 높은 테마가 정리되어 있다.

## Strategy

- [ ] 강조할 경험과 제외할 경험이 모두 적혀 있다.
- [ ] 프로젝트 순서가 JD와 맞다.
- [ ] 부족한 증거를 과장하지 않는다.
- [ ] 회사/JD 표현을 그대로 베끼지 않고 실제 경험과 맞게 번역한다.

## Resume

- [ ] 첫 summary가 JD와 연결된다.
- [ ] bullet은 source page로 역추적된다.
- [ ] 같은 프로젝트 설명을 불필요하게 반복하지 않는다.
- [ ] placeholder가 없다.

## Portfolio

- [ ] 케이스 스터디가 문제, 판단, 행동, 결과로 닫힌다.
- [ ] 각 프로젝트가 JD 요구사항과 연결된다.
- [ ] 수치와 proof가 분리되어 있다.
- [ ] 이력서 문장을 그대로 복사하지 않는다.
