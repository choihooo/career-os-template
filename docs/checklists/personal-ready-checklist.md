# Personal Ready Checklist

개인 사용 100% 기준이다. 이 체크리스트를 통과하면 새 경험을 넣고 범용/맞춤 산출물을 만들 수 있다.

## Data

- [ ] 주요 경험이 `raw/`에 원천 형태로 저장되어 있다.
- [ ] 주요 경험이 `wiki/experiences/`, `wiki/projects/`, `wiki/awards/`, `wiki/skills/` 중 하나로 정규화되어 있다.
- [ ] 강한 수치에는 근거 링크나 raw source가 있다.
- [ ] 근거가 약한 수치와 역할 범위는 `Gaps`에 표시되어 있다.

## Reusable Assets

- [ ] `wiki/themes/positioning.md`에 목표 역할과 차별점이 있다.
- [ ] `wiki/sentence-bank/resume-bullets.md`에 실전 bullet이 20개 이상 있다.
- [ ] `wiki/stories/story-bank.md`에 STAR 스토리가 5개 이상 있다.
- [ ] 각 bullet/story가 source page로 역추적된다.

## Outputs

- [ ] `outputs/general/resume-general-v1.md`가 placeholder 없이 완성되어 있다.
- [ ] `outputs/general/resume-general-v2.md`가 v1과 다른 포지셔닝을 가진다.
- [ ] `outputs/general/portfolio-general-v1.md`가 대표 프로젝트와 proof를 포함한다.
- [ ] `outputs/general/portfolio-general-v2.md`가 내러티브와 signature story를 포함한다.
- [ ] 최종 산출물에 과장된 주장이나 근거 없는 임팩트가 없다.

## Custom Flow

- [ ] JD를 주면 `jd.md`, `analysis.md`, `strategy.md`, `resume.md`, `portfolio.md`가 생성된다.
- [ ] JD와 맞지 않는 강한 경험은 제외 또는 축소된다.
- [ ] 부족한 근거는 `analysis.md`에 gap으로 남는다.
