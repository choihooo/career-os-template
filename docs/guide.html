Career OS를 처음 쓰는 순서

이 템플릿은 채용 지원 자료를 `raw/`, `wiki/`, `outputs/`로 나누고, JD별 맞춤 이력서와 포트폴리오 패키지를 만드는 작업공간입니다.

빠른 시작

  1. 구조 확인Index 페이지에서 샘플 파일과 작업 흐름을 확인합니다.
  2. 프로필 작성`raw/bios/profile.md`에 기본정보와 링크를 채웁니다.
  3. 에셋 정리원본 이미지는 `raw/assets/`, 렌더링용 이미지는 `templates/resume/assets/`, `templates/portfolio/assets/`에 둡니다.
  4. 자료 준비프로젝트, 경력, 수상, JD 자료를 examples 형식에 맞춰 준비합니다.
  5. 위키 반영`career-ingest`로 raw와 wiki를 먼저 채웁니다.
  6. 범용본 생성`career-build-general`로 일반 이력서와 포트폴리오를 만듭니다.
  7. 맞춤 지원실제 JD가 생기면 `career-apply-pipeline`으로 회사별 패키지를 만듭니다.
  8. 렌더링제출용 HTML/PDF가 필요할 때만 rendered workflow를 실행합니다.
  9. 검수체크리스트와 `career-lint`로 누락, 과장, 중복을 확인합니다.

레이어

  • raw/사실 원형, 링크, 메모를 보존합니다.
  • wiki/경험, 프로젝트, 수상, 기술, 스토리, 문장 뱅크를 정규화합니다.
  • outputs/제출 가능한 범용본과 회사별 맞춤본을 보관합니다.
  • templates/Markdown 산출물을 HTML/PDF/카드뉴스로 렌더링하는 템플릿입니다.

원칙

  • 기본 언어는 한국어입니다.
  • 근거 없는 수치, 역할, 임팩트는 만들지 않습니다.
  • 부족한 정보는 `Gaps` 또는 `analysis.md`에 남깁니다.
  • 같은 내용을 직접 복붙하지 않고 wiki를 갱신한 뒤 다시 산출합니다.
