# Application Strategy

## Positioning

React/TypeScript 기반으로 사용자 흐름과 유지보수성을 함께 개선하는 프론트엔드 엔지니어로 포지셔닝한다.

## Emphasize

- 상태관리와 API 데이터 흐름
- 폼 검증과 타입 안정성
- 운영자가 반복하던 업무를 줄인 대시보드 경험

## De-emphasize

- 근거 없는 트래픽, 매출, 대규모 운영 경험
- 백엔드/인프라 주도처럼 보이는 표현
