# JD Analysis

## Target Role

Frontend Engineer

## Must-have Requirements

- React와 TypeScript 기반 제품 개발
- 상태관리와 API 연동 구조 설계
- 인증, 폼, 대시보드 등 사용자 흐름 개선
- 웹 성능 최적화
- 코드 품질과 유지보수성 개선

## Preferred Requirements

- Storybook, Vitest 기반 테스트/문서화
- 디자인 시스템 또는 공통 컴포넌트 개발
- 어드민/대시보드 경험

## Repeated Keywords

- React
- TypeScript
- 상태관리
- 성능 최적화
- 사용자 흐름
- 디자인 시스템
- 테스트/문서화
- 어드민/대시보드

## Candidate Match

- Strong match: 아이겐코리아 TypeScript 마이그레이션, Recoil API 전환, i18n 자동화
- Strong match: 거부기린 Zustand 상태관리, always-on-top UX, 번들 65% 감소
- Strong match: 대피로 디자인 시스템 Compound Component, Storybook/Vitest, ESM/CJS 빌드
- Supporting match: 수상한 녀석들 인증 UX, 멀티스텝 폼, 정성 피드백

## Gaps

- 실제 대규모 운영 트래픽 지표는 없다.
- 디자인 시스템의 실제 패키지 사용처와 다운로드 지표는 아직 없다.
- 수상한 녀석들의 제출 완료율/이탈률 같은 정량 전환 지표는 없다.
