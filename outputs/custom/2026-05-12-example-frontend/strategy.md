# Application Strategy

## Positioning

React와 TypeScript 기반으로 사용자 흐름과 유지보수성을 함께 개선하는 프론트엔드 엔지니어로 포지셔닝한다.

## Emphasize

- TypeScript 마이그레이션과 strict 전환으로 운영 코드 안정성을 높인 경험
- Zustand/Recoil 기반 상태관리 설계 경험
- 번들 65% 감소, 빌드 19% 단축, 요구사항 대응 시간 90% 단축처럼 측정 가능한 개선
- 디자인 시스템, Storybook, Vitest, ESM/CJS 빌드 경험
- 인증, 폼, 알림 UX처럼 사용자가 직접 체감하는 흐름 개선

## De-emphasize

- 오래된 수상 중 현재 프론트엔드 직무와 연결이 약한 항목
- 백엔드, AI 모델 자체를 주도한 것처럼 보이는 표현
- 대규모 트래픽이나 비즈니스 임팩트처럼 근거가 부족한 주장
