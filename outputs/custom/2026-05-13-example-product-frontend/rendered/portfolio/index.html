Case Study 1

Sample Dashboard

운영자가 여러 CSV를 합쳐 보던 주간 지표 확인 흐름을 한 화면의 대시보드로 정리했습니다.

Problem

필터 조건을 공유하기 어렵고, 같은 조건으로 다시 확인하는 과정이 반복적이었습니다.

Decision

서버 데이터 상태와 사용자 필터 상태를 분리하고, 필터 조건은 URL query에 동기화했습니다.

Action

TanStack Query로 로딩, 재요청, 서버 상태를 관리하고 Recharts로 주요 지표와 추세를 시각화했습니다.

Result

운영자로부터 주간 리포트 작성 시간이 2시간에서 30분으로 줄었다는 피드백을 받았습니다.

JD 연결점

대시보드 UI, API 연동 구조, 서버 상태 관리, 운영자 흐름 개선 요구와 직접 연결됩니다.
