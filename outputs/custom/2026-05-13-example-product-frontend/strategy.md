# Application Strategy

## Positioning

React와 TypeScript로 업무용 웹 제품의 데이터 흐름, 필터 재현성, 입력 검증을 개선하는 제품형 프론트엔드 엔지니어로 포지셔닝한다.

## Emphasize

- TanStack Query 기반 서버 상태 분리
- URL query 기반 필터 공유와 재현성
- Zod 기반 입력 검증과 타입 안정성
- 운영자가 반복하던 리포트 확인 흐름을 줄인 대시보드 경험
- B2B SaaS와 어드민 화면에 가까운 업무용 UI 경험

## De-emphasize

- 대규모 트래픽, 매출, 인프라 성과처럼 raw 근거가 없는 표현
- 백엔드/데이터 파이프라인을 주도한 것처럼 보이는 표현
- 실제 증빙이 없는 정량 성과의 단정적 표현

## Message To Recruiter

이 후보는 화면 구현만 강조하기보다, API 응답과 화면 상태를 분리하고 입력 단계에서 오류를 줄이는 방식으로 운영자 경험과 유지보수성을 함께 개선했다는 점을 전면에 둔다.
