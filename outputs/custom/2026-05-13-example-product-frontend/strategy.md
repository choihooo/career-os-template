# Application Strategy

## Positioning

정유진은 React와 TypeScript로 업무용 웹 제품의 데이터 흐름, 필터 재현성, 입력 검증을 개선하는 제품형 프론트엔드 엔지니어로 포지셔닝한다. "예쁜 화면"보다 운영자가 같은 조건을 다시 확인하고, 팀원에게 공유하고, 오류 없이 제출할 수 있게 만드는 사람으로 보여준다.

## Core Narrative

1. 운영자는 같은 데이터를 매주 반복해서 모으고 비교했다.
2. 정유진은 서버 상태, URL 필터, 차트 시각화를 분리해 대시보드 흐름을 재구성했다.
3. 검토 큐와 폼 입력에서는 상태별 UI 규칙과 검증 기준을 명확히 했다.
4. 그 결과 반복 업무 시간과 QA 재현 비용을 줄이는 방향의 프론트엔드 역량을 증명한다.

## Emphasize

- TanStack Query 기반 서버 상태 분리
- URL query 기반 필터 공유와 재현성
- Zod 기반 입력 검증과 타입 안정성
- 운영자가 반복하던 리포트 확인 흐름을 줄인 대시보드 경험
- 검토 큐, 상세 패널, 액션 버튼 상태를 나눈 어드민 워크플로 경험
- QA 재현 경로를 문서화해 커뮤니케이션 비용을 낮춘 태도

## De-emphasize

- 대규모 트래픽, 매출, 인프라 성과처럼 raw 근거가 없는 표현
- 백엔드/데이터 파이프라인을 주도한 것처럼 보이는 표현
- 실제 증빙이 없는 정량 성과의 단정적 표현

## Message To Recruiter

정유진은 화면 구현만 강조하는 후보가 아니라, API 응답과 화면 상태를 분리하고 입력 단계에서 오류를 줄이는 방식으로 운영자 경험과 유지보수성을 함께 개선한 후보입니다. 특히 B2B SaaS의 대시보드, 테이블, 폼 화면을 반복적으로 다뤄본 점이 이 JD와 맞습니다.
