# JD Analysis

## Target Role

React와 TypeScript 기반 B2B SaaS 프론트엔드 엔지니어.

## Must-have Requirements

- React/TypeScript 기반 제품 화면 구현
- API 응답, 서버 상태, URL 상태를 고려한 상태 설계
- 폼, 테이블, 대시보드 등 업무용 UI 구현
- 사용자 흐름을 기준으로 요구사항을 화면 구조로 구체화
- Git 기반 협업과 코드 리뷰

## Preferred Requirements

- TanStack Query, Zod, Recharts 사용 경험
- 어드민 또는 B2B SaaS 제품 개발 경험
- QA 이슈를 입력 단계에서 차단한 경험
- 반복 업무 시간을 줄인 경험

## Repeated Keywords

- React
- TypeScript
- 대시보드
- 상태관리
- API 연동
- 폼 검증
- 운영자 흐름
- 유지보수성

## Candidate Match

- Strong match: `Sample Dashboard`에서 TanStack Query로 서버 상태를 분리하고, URL query로 필터 상태를 공유 가능하게 만든 경험.
- Strong match: `Sample Company`에서 Zod 스키마와 명시 타입을 적용해 QA 재현 이슈 5건 중 4건을 입력 단계에서 차단한 경험.
- Supporting match: Recharts를 사용해 운영 지표와 추세를 한 화면에서 확인하도록 만든 경험.

## Gaps

- 샘플 후보이므로 실제 회사명, GitHub 링크, PR 링크, 스크린샷, 사용자 피드백 원문으로 교체해야 한다.
- 주간 리포트 시간이 2시간에서 30분으로 줄었다는 내용은 운영자 피드백 기반이므로, 실제 제출 전 측정 방식이나 증빙을 보강해야 한다.
- Git 기반 협업과 코드 리뷰 경험은 샘플 raw에 구체 PR 근거가 없으므로 강하게 주장하지 않는다.
