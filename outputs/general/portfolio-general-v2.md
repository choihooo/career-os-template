# General Portfolio v2

## Narrative

좋은 프론트엔드 작업은 화면 구현에서 끝나지 않는다. 사용자가 어디서 막히는지, 팀이 어떤 작업을 반복하는지 보고, 상태관리와 검증 구조로 그 비용을 줄인다.

## Signature Strengths

### 1. 입력 오류를 사전에 줄인다

- 폼 스키마와 타입 정의를 정리해 QA 단계로 넘어가던 오류를 줄였다.

### 2. 상태 흐름을 재현 가능하게 만든다

- URL query와 서버 상태를 분리해 필터 조건을 공유 가능하게 만들었다.

## Project Story

### Sample Dashboard

운영자는 여러 파일을 오가며 주간 리포트를 만들고 있었다. 필터 조건을 URL에 동기화하고 서버 상태를 분리해 같은 조건을 다시 열거나 공유할 수 있게 했다.

## Notes

- 이 파일은 템플릿 샘플이다. 실제 제출 전 자기 프로젝트와 증거로 교체한다.
