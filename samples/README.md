# Samples

이 폴더는 템플릿 설명과 데모 검증에 필요한 샘플 자료를 모아 둔 곳이다.

## 역할

- `samples/raw/`: 샘플 후보 프로필, 샘플 JD, 샘플 경험/프로젝트/수상 원천
- `samples/wiki/`: 샘플 raw를 바탕으로 만든 정규화 페이지
- `samples/custom-packages/`: 샘플 JD 기준으로 생성한 맞춤 패키지. `source/`, `research/`, `final/` 구조를 따른다.

## 원칙

- 실제 사용자 자료는 `raw/`, `wiki/`, `outputs/` 아래에서 관리한다.
- 템플릿 설명용 예시와 데모 산출물은 `samples/` 아래에서 관리한다.
- 샘플 경로는 실제 제출용 경로와 섞지 않는다.
- 샘플 rendered 결과는 구조 설명과 회귀 확인 용도로 `final/` 아래에 유지할 수 있다.
