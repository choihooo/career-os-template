# Example Product Frontend JD

## Company

Example Product

## Role

Frontend Engineer

## Responsibilities

- React와 TypeScript 기반 웹 제품 화면 개발
- 운영자가 반복 사용하는 대시보드, 테이블, 필터 UI 개선
- API 응답, 서버 상태, URL 상태를 고려한 화면 상태 설계
- 폼 입력 검증과 에러 메시지 UX 개선
- 기획, 디자인, QA와 함께 요구사항을 화면 구조로 구체화
- 코드 품질, 타입 안정성, 문서화를 통한 유지보수성 개선

## Requirements

- React와 TypeScript 프로젝트 경험
- 서버 상태 관리 또는 API 연동 구조 설계 경험
- 제품 요구사항을 사용자 흐름과 UI 구조로 풀어낸 경험
- 폼, 테이블, 대시보드 등 업무용 화면 구현 경험
- Git 기반 협업과 코드 리뷰 경험

## Preferred

- TanStack Query, Zod, Recharts 사용 경험
- 어드민 또는 B2B SaaS 제품 개발 경험
- QA 이슈를 재현하고 입력 단계에서 차단한 경험
- 사용자 피드백을 바탕으로 반복 업무 시간을 줄인 경험
