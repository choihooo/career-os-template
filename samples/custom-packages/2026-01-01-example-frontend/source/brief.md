# Application Brief

## Target Role

Frontend Engineer

## Must-have Requirements

- React/TypeScript 기반 웹 제품 개발
- 상태관리와 API 연동 구조 설계
- 폼과 대시보드 UI 개선

## Preferred Requirements

- 어드민/대시보드 경험
- 테스트/문서화 경험

## Repeated Keywords

- React
- TypeScript
- 상태관리
- 대시보드
- 사용자 흐름

## Evaluation Themes

- 사용자 흐름을 화면 구조로 풀어내는 역량
- 상태관리와 데이터 흐름 설계
- 입력 검증과 타입 안정성

## What To Emphasize

- Sample Dashboard의 URL filter와 TanStack Query 기반 데이터 흐름
- Sample Company의 폼 검증과 타입 안정성 개선
- 운영자가 반복하던 업무를 줄인 대시보드 경험

## What To De-emphasize

- 근거 없는 트래픽, 매출, 대규모 운영 경험
- 백엔드/인프라 주도처럼 보이는 표현

## Leading Projects And Stories

- `Sample Dashboard`
- `Sample Company Form Validation`

## Gaps And Claims To Avoid

- 샘플 데이터이므로 실제 링크, PR, 사용자 피드백, 수치 근거로 교체해야 한다.
